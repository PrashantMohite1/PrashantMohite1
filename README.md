### My Projects

#### [Docklens](https://github.com/PrashantMohite1/docklens)
A long-term open-source project to make Docker-related debugging faster. It's a Go CLI built for inspecting and troubleshooting production Docker images and containers. The first feature is live: it hashes files/folders inside an image against a reference so you can confirm the right production files actually made it into the container. Many more features are on the way.

#### [cloud-k8s-playbook](https://github.com/PrashantMohite1/cloud-k8s-playbook)
A single, comprehensive home for production-grade Terraform covering managed Kubernetes on AWS, Azure, and GCP, with best practices baked in. AWS EKS is done, with the required Terraform and full docs. Azure AKS and GKE are on the roadmap.

#### [k8s-cluster-provisioner](https://github.com/PrashantMohite1/k8s-cluster-provisioner)
Sometimes you just need a self-managed cluster for practice, testing, or a lower environment. This automates self-managed `kubeadm` cluster creation on AWS EC2 with Terraform and bash: one `terraform apply`, and you've got a ready-to-use cluster in about 10 minutes.
